Kllosha inicioi **EdaS** — web app për krijimin e muzikës me AI për mbesën e tij, Eda Selimi (16 vjeçe).

### Arkitektura
- **Backend:** Python FastAPI (si AvokatIM)

- **LLM:** DeepSeek V4 (tekstet, struktura, prompt engineering)
- **Muzika:**
  - Suno API (këngë të plota me vokal) — premium
  - MusicGen (Meta, open source) — lokal, pret RTX 3060
  - HuggingFace API (fallback cloud) — në proces krijimi llogarie
- **DB:** PostgreSQL (e njejta instancë si AvokatIM)
- **Auth:** Simple JWT (single-user MVP)
